# Changelog

## v0.2.0 — Realistic radio UI preview

- Replaced flat drawn housings with realistic handheld and mobile skins based on the supplied references.
- Aligned clickable buttons, rotary controls, and live LCD content with the physical radio artwork.
- Hid the toolbar in click-through mode and restored it when unlocked.
- Retained the PR logo as the app icon, tray icon, and toolbar branding.
- Preserved TeamSpeak channel selection, volume, speaker status, and native push-to-talk use.

Build, control-routing, visual, and desktop smoke checks passed. Live voice and ERLC gameplay remain to be tested. The bridge component remains version 0.1.0.

## v0.1.0 — Initial local prototype

- Added two radio layouts, the Windows overlay, hotkeys, tray controls, and a TeamSpeak 3 bridge.
