**PR Radios v0.2.0 — Realistic Radio UI Preview**

A Windows radio overlay for TeamSpeak 3, with realistic handheld and mobile layouts, the PR logo, and live channel/speaker information.

### Download

Download **PR-Radios-v0.2.0-win64.zip** from the release assets and extract it. This is the ready-to-run app; GitHub's source-code ZIP is for building it yourself.

### Install

1. Close TeamSpeak 3.
2. Open **PR-Radios-Bridge.ts3_plugin** from the extracted folder and install it.
3. Reopen TeamSpeak, enable **PR Radios Bridge**, and join your server.
4. Run **PR-Radios.exe** and set your push-to-talk key in TeamSpeak.

Use windowed or borderless gameplay. **Ctrl+Alt+R** toggles click-through, **Ctrl+Alt+H** shows/hides the radio, and **Ctrl+Alt+S** switches models.

### Changes

- Realistic textured radio housings, recessed LCDs, knobs, and buttons.
- Working channel/volume controls aligned to the artwork.
- A toolbar that hides in click-through mode.
- PR branding and custom app/tray icon.

### Status

Requires Windows 64-bit and TeamSpeak 3 plugin API 26; targets Windows 11 with TS3 3.6.2. TeamSpeak 6 is not supported. This app uses your TeamSpeak communications; it does not connect to ERLC's built-in radio.

This is an **unsigned pre-release**. Build, visual, bridge simulation, UI-routing, and desktop smoke checks passed. Live voice and gameplay remain untested. The app is version 0.2.0; its bridge remains version 0.1.0.
