Extract the ZIP on Windows PC.
Install TeamSpeak 3, 64-bit, if needed.
Close TeamSpeak, then double-click PR-Radios-Bridge.ts3_plugin to install the bridge.
Reopen TeamSpeak, enable PR Radios Bridge under Tools → Options → Addons, and join your TeamSpeak server.
Run PR-Radios.exe, configure push-to-talk in TeamSpeak, and open Roblox.
